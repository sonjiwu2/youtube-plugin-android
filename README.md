# Youtube Plugin

Open-source приложение для обхода ограничений YouTube на Android.

[![Все релизы](https://img.shields.io/badge/Все_релизы-GitHub-252735?style=for-the-badge)](https://github.com/sonjiwu2/youtube-plugin-android/releases)

## Начало работы

1. Установите APK из [последнего релиза](https://github.com/sonjiwu2/youtube-plugin-android/releases/latest). Для большинства телефонов подойдёт **arm64-v8a**, если не уверены — **universal**.
2. Откройте Youtube Plugin, включите **«Подключение»** и подтвердите запрос VPN от Android.
3. Дождитесь подбора стратегии и откройте обычное приложение **YouTube**. Ваш аккаунт, подписки и история остаются в нём.

Плагин продолжает работать после закрытия своего экрана. Чтобы отключить обход, выключите тумблер или нажмите **«Выключить»** в уведомлении. Обновления устанавливаются поверх предыдущей версии.

## Возможности

- Автоматический подбор стратегии и сохранение подходящей для вашей сети.
- Работа в фоне, восстановление связи и автозапуск после перезагрузки.
- Зашифрованный DNS с выбором провайдера и подписанные обновления стратегий.
- Скорость приёма и передачи, график трафика и статистика сеанса.
- Светлая и тёмная темы, ручной выбор стратегии и плитка быстрых настроек Android.

## Что нужно знать

Android 7.0+ и установленный официальный YouTube. Root и внешний VPN не нужны: локальное VPN-подключение обрабатывает только трафик YouTube на телефоне, IP вашего провайдера сохраняется. Одновременно использовать другой VPN нельзя.

Для устойчивой работы разрешите приложению фоновую работу без ограничений батареи. Принудительная остановка Android или отзыв разрешения VPN отключают сервис. Результат обхода зависит от оператора; блокировки по IP и белые списки могут оставаться недоступными.

При проблемах откройте **«О приложении → Диагностика подключения»**, приложите отчёт к [сообщению об ошибке](https://github.com/sonjiwu2/youtube-plugin-android/issues) и укажите оператора и город.
