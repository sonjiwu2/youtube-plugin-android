# Youtube Plugin

Open-source приложение для обхода ограничений YouTube на Android. Без внешнего VPN и root, с IP вашего провайдера.

[![Скачать Youtube Plugin 0.1.0](https://img.shields.io/badge/Скачать-Youtube%20Plugin%200.1.0-83b84b)](https://github.com/sonjiwu2/youtube-plugin-android/releases/latest)
![Android 7.0+](https://img.shields.io/badge/Android-7.0%2B-83b84b)

## Установка

Скачайте [Youtube Plugin из последнего релиза](https://github.com/sonjiwu2/youtube-plugin-android/releases/latest), установите APK и нажмите **«Открыть YouTube»**. Обновления устанавливаются поверх предыдущей версии.

## Возможности

- Автоматический подбор из 18 стратегий и сохранение настроек для вашей сети.
- Зашифрованный DNS и подписанные обновления стратегий.
- Поиск, полноэкранное видео, «картинка в картинке», светлая и тёмная темы.
- Скорость загрузки видео и отчёт о подключении.

Обход действует внутри Youtube Plugin. Работа зависит от сети оператора.

При проблемах приложите отчёт через **«Поделиться отчётом»** к [сообщению об ошибке](https://github.com/sonjiwu2/youtube-plugin-android/issues), укажите оператора и город.
