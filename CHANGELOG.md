## [0.1.0] — 2026-10-23

### Этапы 1–2 — сетевой движок
- Go CONNECT-прокси, ограниченный разбор TLS/SNI, hostlist с точными и суффиксными правилами.
- DoH A/AAAA с IPv4/IPv6 bootstrap через ciadpi, объединением параллельных запросов и TTL-кэшем.
- Закреплённый ciadpi 17.3 под arm64-v8a, armeabi-v7a, x86_64, ELF alignment 16 КБ.
- Восемь userspace-пресетов и TLS-образец Google с полными MIT-уведомлениями.
- Unit/race-тесты, локальный сквозной TLS/SOCKS-тест и живой тест m.youtube.com.

### Этапы 3–4 — приложение и устойчивость
- Kotlin/Compose WebView после подтверждённого proxy override без direct fallback.
- Жизненный цикл движка, автостарт при смене сети, отпечаток сети без SSID/геолокации.
- Подбор по сбоям и скорости видео, кэш успешной стратегии, конечный экран ошибки.
- Отмена соединения браузером не ухудшает оценку стратегии.
- Офлайн-состояние, ручной повтор, уведомление и плитка быстрого запуска.

### Этапы 5–6 — обновления и интерфейс
- Ed25519 конфиги с проверкой подписи, срока и версии; стабильный release `strategies`.
- Скрипты создания ключей, подписи и публикации, приватные ключи исключены из Git.
- Онбординг, светлая/тёмная темы, полноэкранное видео и PiP.
- Индикатор скорости, ручное сравнение видеофрагмента до/после обработки, очистка cookies/cache.
- Имя «Разгон», пакет ru.razgon.app.

### Этап 7 — выпуск
- Постоянная подпись APK, universal и отдельные сборки для трёх ABI.
- GitHub Actions: Go vet/race, native/gomobile, Android lint и debug на main/PR.
- Публикация подписанных APK и SHA256SUMS по тегу v*.
- Актуальные инструкции сборки, проверки ПК, remote-config и ограничения.

### Этап −1 — исследование
- Разобраны все 22 варианта `general*.bat` Flowseal, семантика nfqws/tpws, язык аргументов ciadpi.
- Составлена таблица «методика zapret → аргумент ciadpi → применимость без root» (`docs/RESEARCH.md`).

### Этап 0 — каркас
- Gradle Kotlin DSL + version catalog, AGP 9.4, встроенный Kotlin, Compose BOM.
- Минимальный модуль приложения `ru.razgon.app` (minSdk 24, compileSdk 37), отображаемое имя «Ютуб Mod».
- README, LICENSES.md, дорожная карта, заготовка CI.
