# Проверка VPN на устройстве

Модуль `probe` — отдельное тестовое приложение с UID `ru.youtubeplugin.probe`. Это позволяет проверять путь Android VPN → netstack → ciadpi независимо от внутреннего контрольного запроса самого плагина.

1. Соберите `:qa:probe:assembleDebug` и `:app:assembleDebug`.
2. Установите оба APK на тестовое устройство с официальным YouTube. Включите подключение в debug-плагине после установки probe.
3. Убедитесь в `dumpsys connectivity`, что VPN содержит UID YouTube и probe; UID плагина должен быть исключён.
4. Запустите `ru.youtubeplugin.probe/.ProbeActivity`. Результат: `adb shell run-as ru.youtubeplugin.probe cat files/report.txt`.
5. Проверьте рост счётчиков в `adb shell run-as ru.razgon.app cat cache/vpn-diagnostics.json`. Первый запрос до установления TUN мог пройти по старому маршруту — такой результат не подтверждает VPN. Повторите probe после запуска интерфейса.

Ожидаемые HTTP-ответы: `m.youtube.com` — 200; тест GET к API browse — 405 (метод намеренно неподходящий, подтверждает доступность TLS/HTTP); превью `i.ytimg.com` — 200; generate_204 — 204. Отдельный URL можно задать строковым extra `url`.

Далее проверьте просмотр в официальном YouTube, фон после Home/закрытия Activity, тумблер OFF, действие уведомления, плитку, потерю и возврат сети, восстановление процесса и автозапуск после reboot. Эти действия выполняйте только на выделенном тестовом устройстве.

Тестовый UID и запись приватного debug-отчёта отсутствуют в release APK. Probe не публикуется в Releases.

## Полный прогон стратегий

`qa/strategies.ps1` предназначен только для выделенного эмулятора. Сценарий перебирает 18 ручных стратегий, очищает временный кэш AVD, открывает настоящий YouTube и сверяет новые байты CDN с продвижением плеера. Сохраняются JSON, XML экранов и кадры. Ответы HTML/API сами по себе не считаются подтверждением просмотра. Входные экраны cookies и системные окна эмулятора требуют отдельной проверки результатов.

## Встроенная проверка и экспорт

В плагине откройте «Проверка YouTube», запустите проверку и включите ролик в обычном YouTube. Через 45 секунд доступны отдельные результаты HTML/API, дельты трафика YouTube, видеоданные, пиковая скорость и посекундные выборки. Внутренние HTTP-проверки исключены из счётчиков VPN. Из счётчика видеоданных консервативно исключены первые 32 КиБ каждого CDN-соединения, чтобы повторные TLS-рукопожатия не давали ложного успеха. HTTPS не расшифровывается; факт декодирования кадров отдельно проверяется в плеере. Последний отчёт сохраняется в приватных файлах и доступен после перезапуска экрана.

В debug APK shell может вызвать `.QaActivity --ez check true` без открытия YouTube: при принудительно остановленном YouTube внутренние проверки не должны создавать видеотрафик. QA-экран требует системного разрешения DUMP и отсутствует в release.

Для проверки экспорта production APK установите probe, выполните встроенную проверку, нажмите «Отправить отчёт» и выберите локальный **QA report**. Полученный текст: `adb shell run-as ru.youtubeplugin.probe cat files/shared-report.txt`. Это локальная передача на том же AVD, без отправки на сервер. В production VPN UID probe исключён.
