# Дорожная карта

Статус этапов и принятые решения. Файл обновляется в конце каждого этапа, так что по нему
можно продолжить работу с любого места.

| Этап | Содержание | Статус |
|---|---|---|
| −1 | Исследование первоисточников → `docs/RESEARCH.md` | ✅ |
| 0 | Каркас: Gradle, модуль app, документы, CI | ✅ |
| 1 | Go-ядро: CONNECT-прокси, SNI, hostlist, DoH, стратегии, Ed25519 | ⏳ |
| 2 | ciadpi: сборка под ABI, SOCKS5-апстрим, пресеты в JSON | ⬜ |

## Ключевые решения

* **Имена.** Пакет `ru.razgon.app`, отображаемое имя «Ютуб Mod» (выбор владельца репозитория),
  кодовое имя «Разгон». Иконка без логотипа YouTube.
* **Сборочный стек** (проверен по maven-metadata на 2026-10-23): Gradle 9.8.2, AGP 9.4.1
  (встроенный Kotlin, `org.jetbrains.kotlin.android` не применяется), Kotlin 2.4.21,
  Compose BOM 2026.09.00, compileSdk 37, targetSdk 36, NDK 28.2.13676358.
  Configuration cache выключен из-за несовместимости AGP 9.4 и Gradle 9.8.
* **ciadpi — отдельным процессом**, исполняемый файл `lib<abi>/libciadpi.so` в `nativeLibraryDir`
  (обоснование в RESEARCH.md §7). Go-ядро само запускает и останавливает ciadpi.
* **QUIC не обрабатываем**: через HTTP-прокси WebView использует только TCP.
* **Git**: `main` держится в рабочем состоянии, этапы разрабатываются в ветках `feature/*`
  и вливаются через `--no-ff`.

## Как продолжить работу

1. `git clone` репозитория, установить SDK/NDK/Go по README.
2. `cd core && go test ./...` и `./gradlew :app:assembleDebug` должны быть зелёными.
3. Взять первый этап со статусом ⏳ или ⬜ и выполнить его по критерию готовности из брифа.
