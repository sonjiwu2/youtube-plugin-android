# Состояние проекта: 0.2.0

| Компонент | Реализовано |
|---|---|
| Внешний YouTube | Локальный per-app VPN для официального приложения с его аккаунтом |
| Фон | ForegroundService, сохранённое включение, sticky restart, автозапуск и восстановление сети |
| Сетевой стек | gVisor/tun2socks, TCP/SOCKS, DNS через HTTPS, отказ QUIC, IPv4/IPv6 |
| Обход DPI | ciadpi, 18 встроенных стратегий, HTTPS-проверка, ручной выбор и сетевой кэш |
| Стратегии | Ed25519, проверка срока/версии, обновление без APK |
| Интерфейс | Новый dashboard, трафик и график, темы, настройки, диагностика, новая иконка |
| Управление | Тумблер, действие уведомления и плитка Android |
| Распространение | Постоянная подпись, отдельные GitHub Releases и четыре APK |

Исходный WebView-прототип сохранён в истории 0.1.0. В актуальной версии браузер удалён. Конкретные результаты и границы проверки приведены в [VALIDATION.md](VALIDATION.md). Работа на операторской сети оценивается по тесту устройства; сборка не может гарантировать обход каждого вида блокировки.
