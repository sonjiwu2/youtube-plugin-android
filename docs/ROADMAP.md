Пакет `ru.razgon.app` сохранён для обновления ранее установленных APK. Имя в launcher и интерфейсе —
«Youtube Plugin». Движок — отдельный исполняемый процесс
`libciadpi.so` из `nativeLibraryDir`. Go-ядро не зависит от Android.

Реальный разгон видео в каждой сети не является универсально подтверждаемым свойством сборки:
проверяйте поток у своего оператора. Эмулятор и тест доступности главной страницы не заменяют
проверку на физическом телефоне. Известные ограничения перечислены в README.
