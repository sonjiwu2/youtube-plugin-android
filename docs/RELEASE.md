Обновлены файлы существующего выпуска: **Разгон 0.1.1**. Устанавливается поверх 0.1.0 с сохранением подписи.

### Что изменилось

- Исправлен подбор подключения: YouTube проверяется до открытия браузера.
- Добавлены составные способы обхода — всего 18 стратегий.
- Исправлена обработка TLS-соединений и запасной доступ к зашифрованному DNS.
- Вместо штатной страницы ошибки показывается состояние подбора.
- Кнопка **«Поделиться отчётом»** помогает разобрать сбой у конкретного оператора.

### Какой APK скачать

**arm64-v8a** — для большинства современных телефонов. **universal** — если архитектура неизвестна.
**armeabi-v7a** — для 32-битных устройств, **x86_64** — для соответствующих планшетов и эмуляторов.

Отключите внешний VPN, откройте «Разгон» и дождитесь подбора. Приложение сохраняет IP вашего провайдера
и работает с YouTube внутри своего окна. Трафик официального приложения YouTube оно не обрабатывает.

Проверены автоматические сборки, главная страница, поиск и воспроизведение видео на тестовом Android.
Работа на физическом телефоне в сети Дом.ру, Нижний Новгород, пока не подтверждена.
Если подключение не заработало, приложите отчёт из приложения и укажите оператора и город.

Подписанные обновления стратегий загружаются автоматически; отдельный служебный релиз для них больше не нужен.
