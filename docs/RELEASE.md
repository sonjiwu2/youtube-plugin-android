**Youtube Plugin** — open-source приложение для обхода ограничений YouTube на Android, без внешнего VPN и root. Подключение сохраняет IP вашего провайдера.

В первом выпуске:

- Поиск и просмотр YouTube внутри приложения.
- Автоматический подбор из 18 стратегий с проверкой доступности YouTube и сохранением подходящей для вашей сети.
- Зашифрованный DNS и подписанные обновления стратегий.
- Полноэкранное видео, «картинка в картинке», светлая и тёмная темы.
- Индикатор скорости и отчёт о подключении для разбора ошибок.

**Начало работы:** установите APK, откройте Youtube Plugin и нажмите **«Открыть YouTube»**. Android 7.0+.

Обход действует внутри приложения; результат зависит от сети оператора. При проблемах приложите отчёт о подключении к сообщению об ошибке.
