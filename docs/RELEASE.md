Open-source приложение для обхода ограничений YouTube на Android.

- Без внешнего VPN и root, с IP вашего провайдера.
- Автоматический подбор из 18 стратегий, зашифрованный DNS.
- Полноэкранное видео и «картинка в картинке».

**Установка:** скачайте APK, установите и нажмите «Открыть YouTube». Android 7.0+.
Обход работает внутри приложения; результат зависит от сети оператора.
