# Проверки 0.2.0

23–24 октября 2026. Windows x64, Go 1.26.3, JDK 17, SDK 37, NDK r28c. Устройство: выделенный эмулятор Android x86_64 API 36.1 с официальным YouTube 20.10.41.

## Ядро и сборка

- Go vet и полный набор race-тестов; Linux-проверки GitHub Actions.
- Настоящие IP-пакеты через TUN-эквивалент socketpair: DNS-ответ, ICMP port-unreachable для QUIC, TCP RST до SYN-ACK для неподдерживаемого назначения, сохранение владения FD после остановки.
- Проверки DNS: A/AAAA, ошибочные сообщения, отказ служебным адресам, резерв провайдера в автоматическом режиме и сохранение явно выбранного DNS.
- Ручная стратегия не заменяется автоматически. Низкий битрейт/паузы видеоплеера не вызывают перебор работающих стратегий. Проверяется обнаружение завершившегося native-процесса.
- Сохранены проверки TLS/SNI, CONNECT/SOCKS, выбора стратегий, подписей Ed25519, срока конфигурации и отмены соединений.
- Native/gomobile: arm64-v8a, armeabi-v7a, x86_64. Android debug, release с R8 и lint проходят. Выпускаются четыре подписанных APK; package `ru.razgon.app`, versionCode 5, versionName 0.2.0.

## На Android

- Production APK установлен обновлением с прежней подписью без удаления данных. Проверены имя приложения, версия и ABI.
- Разрешение VPN выдаётся стандартным системным диалогом. В production allowlist присутствует только UID YouTube; UID плагина и отдельного probe исключены.
- Официальный YouTube загрузил страницу видео и воспроизводил **Big Buck Bunny 60fps 4K — Official Blender Foundation Short Film**: получены видеокадры и состояние PLAYING, росли счётчики HTTPS-трафика. Экран плагина в это время закрыт.
- Debug-probe с отдельным UID проверил HTTPS главной страницы (200), доступность API (405 для тестового GET), превью (200) и generate_204 (204). Результаты сверялись с allowlist и счётчиками, чтобы исключить старый прямой маршрут до запуска TUN.
- Проверено сохранение включения и настроек. После перезагрузки Android при включённом автозапуске foreground-сервис и ciadpi запустились без открытия Activity.
- При отсутствии Wi-Fi и мобильной сети экран показывает ожидание сети, тумблер остаётся включённым, native-движок останавливается, VPN-интерфейс сохраняется. После возврата сети выполняется переподключение.
- В тестовой сети обнаружен случай недоступных адресов одного DNS-провайдера; проверены выбор Cloudflare и автоматический резерв DNS. Финальный production APK подключился с автоматическими стратегией и DNS.
- Ручной выбор стратегии и DNS сохраняется и применяется; проверены светлая/тёмная темы, системные панели, автозапуск и настройка скорости уведомления.
- Плитка быстрых настроек действительно выключает VPN/ciadpi и включает обратно. Остановка не привязана к Activity.
- При завершении основного процесса native-процесс не остаётся работающим. `START_STICKY` запрашивает восстановление у Android; немедленный перезапуск после SIGKILL не гарантируется системой.

## Границы

Физический ARM-телефон и конкретная линия Дом.ру в Нижнем Новгороде с 0.2.0 здесь не тестировались. ARM ABI проверены сборкой. Эмулятор использует сеть ПК; его результат не доказывает доступность и скорость на любом операторе. Вход в Google-аккаунт на эмуляторе не выполнялся: плагин использует существующее приложение YouTube и не управляет его данными аккаунта.

Последние автоматические результаты доступны в [Actions](https://github.com/sonjiwu2/youtube-plugin-android/actions), APK — в [Releases](https://github.com/sonjiwu2/youtube-plugin-android/releases).
