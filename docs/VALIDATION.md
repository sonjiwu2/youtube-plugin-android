# Проверки выпуска 0.1.0

Дата: 23 октября 2026. Рабочая среда: Windows x64, Go 1.26.3, JDK 17,
SDK 37, NDK r28c, CMake 3.31.6. Android: эмулятор x86_64 API 36.1.

## Автоматические проверки

- `go vet ./...`, `go test -race -timeout 120s ./...`.
- TLS/SNI: настоящий ClientHello Go TLS, усечённые и разделённые TLS-рекорды, fuzz seed.
- Hostlist: суффиксы, точные правила, похожие имена; запрет частных и служебных IP.
- Ed25519: корректная подпись, подмена байтов, понижение версии, истёкший конфиг.
- DoH fallback: только точные имена, запрет подмены CDN общим адресом.
- SOCKS5: числовой IP вместо имени; полный TLS-туннель через локальные CONNECT/SOCKS.
- Жизненный цикл: закрытие listener; ограниченный перебор, ошибки устаревших соединений.
- Отмена соединения клиентом не считается неудачей desync.
- URL замера: только HTTPS googlevideo.com без credentials и постороннего порта.
- Native CMake: arm64-v8a, armeabi-v7a, x86_64; ELF LOAD alignment 0x4000 (16 КБ).
- Gradle: debug, lintDebug, release с R8 и четырьмя подписанными APK.

## Живые проверки

- `TestLiveProxy`: HTTPS m.youtube.com через CONNECT → ciadpi → IP из DoH,
  HTTP 200, около 963 КБ распакованного содержимого страницы.
- Установка и запуск debug APK на API 36.1, онбординг и загрузка мобильной страницы YouTube.
- Автоматическая смена стратегии, вывод активного профиля сети.
- При Home процесс ciadpi исчезает; при возврате создаётся новый.
- Офлайн-экран после отключения Wi-Fi/мобильной сети, восстановление после включения.
- Повторный живой тест после исправлений: HTTP 200, 953675 байт за 2,6 с.
- `TestLiveSignedUpdate`: подписанный JSON из GitHub Releases принят за 3,2 с,
  применена версия 1792767611. На Android созданы проверенные `remote.json` / `remote.sig`.

## Границы проверки

Физический ARM-телефон не был подключён: эти ABI проверены сборкой.
HTTP 200 главной страницы не доказывает скорость видео в конкретной сети.
Эмулятор использует сеть ПК, его результат не переносится на всех операторов.
Финальные результаты CI и опубликованные APK доступны на вкладках Actions и Releases.
